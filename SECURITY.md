# Сообщение об уязвимости

Не публикуйте детали уязвимости, токены, базу данных или пользовательские данные в открытом issue.

Если репозиторий опубликован на GitHub и включены Security Advisories, отправьте private vulnerability report через вкладку **Security** репозитория. До выбора владельцем канала для private reports не прикладывайте секреты и не публикуйте эксплуатационные данные.

## Секреты и данные

- Telegram bot token хранится только в локальном `.env` или защищённых переменных окружения.
- `.env`, SQLite-файлы, резервные копии и журналы не должны попадать в Git.
- При утечке токена немедленно отзовите его через @BotFather.
- Публичные сценарии доступны всем, у кого есть ссылка; не размещайте в них конфиденциальную информацию.
