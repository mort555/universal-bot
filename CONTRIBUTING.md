# Участие в разработке

## Локальная настройка

Создайте виртуальное окружение и установите зависимости:

```bash
python -m venv .venv
python -m pip install -r requirements.txt
```

Для тестов `.env` и Telegram-токен не нужны. Для ручной проверки бота создайте `.env` из `.env.example`.

## Проверки перед pull request

```bash
python -m unittest discover -s tests -v
python -m compileall -q main.py storage.py tests
```

## Рекомендации к изменениям

- Сохраняйте границы владения: операции редактирования должны проверять owner ID и принадлежность сущности проекту.
- Для поведения SQLite добавляйте целевые тесты с временной базой.
- Не добавляйте реальные токены, пользовательские базы, логи и файлы окружения.
- Старайтесь сохранять совместимость с Python 3.10 и текущей версией aiogram 3.
- Обновляйте README или документацию, если меняются установка, конфигурация или пользовательские действия.

## Pull request

Опишите цель изменения, пользовательское поведение, способ проверки и любые ограничения или миграции данных. Убедитесь, что CI проходит.
