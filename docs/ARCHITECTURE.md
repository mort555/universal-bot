# Архитектура

## Обзор

Приложение — асинхронный Telegram-бот на aiogram 3. Оно совмещает конструктор и движок запуска сценариев в одном боте:

- владелец создаёт и редактирует сценарии в личном чате;
- посетитель открывает опубликованный сценарий по deep link;
- нажатия кнопок показывают следующие страницы сценария.

В проекте нет отдельного веб-сервера или клиентского приложения.

## Компоненты

### `main.py`

- Создаёт aiogram `Router` и `Dispatcher`.
- Обрабатывает команды, inline-кнопки и сообщения.
- Использует FSM для многошагового ввода названий и текста.
- Перед изменением сценария проверяет владельца по Telegram user ID.
- Формирует публичные страницы и кнопки переходов.

### `storage.py`

Класс `Database` инкапсулирует операции SQLite. Каждая операция открывает и закрывает соединение. Внешние значения передаются SQL через параметры.

### `tests/`

Модульные тесты используют временную базу SQLite и проверяют владение, переходы, удаление и переименование. Telegram-токен для них не нужен.

## Модель данных

```text
projects (1) ── (*) pages
pages (1) ── (*) buttons.source_page_id
pages (1) ── (*) buttons.target_page_id
```

- `projects.owner_id` — Telegram ID владельца.
- `projects.is_published` — доступность публичного сценария.
- Первая созданная страница проекта — стартовая.
- Кнопка хранит страницу-источник, страницу-назначение и подпись.
- При создании целевой страницы из диалога кнопки запись страницы и кнопки сохраняется одной транзакцией.
- Внешние ключи SQLite удаляют связанные кнопки при удалении страницы и страницы при удалении проекта.

## Поток публичного сценария

1. Deep link `/start flow_<project_id>` находит опубликованный проект.
2. Бот показывает первую страницу по возрастанию ID.
3. Кнопки страницы содержат ID проекта и целевой страницы.
4. При нажатии бот проверяет публикацию проекта и принадлежность страницы проекту, после чего отображает её.

Публичный контент не требует аккаунта владельца, но изменять и удалять его может только владелец.

## Состояние и хранение

Постоянные данные хранятся в SQLite (`BOT_DB_PATH`, по умолчанию `data/bot.sqlite3`). Незавершённые шаги ввода хранятся в `MemoryStorage` aiogram и сбрасываются при перезапуске процесса.

Для переноса установки остановите бота и перенесите файл базы данных вместе с конфигурацией. Не используйте один SQLite-файл на нескольких независимых хостах.

## Известные ограничения

- Одна кнопка ведёт на одну страницу; условий и динамических ветвлений нет.
- Контент страницы — текст; вложения и форматирование как отдельные элементы конструктора не поддерживаются.
- Стартовую страницу нельзя удалить или переназначить.
- При одновременной работе нескольких экземпляров один Telegram bot token может получать конфликты polling; запускайте один экземпляр.
